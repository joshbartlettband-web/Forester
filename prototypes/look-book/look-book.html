Barn quilt modifiers

Each modifier is a painted barn quilt. Common ones use traditional blocks. Rarer ones get a block generated from the modifier itself, and the rarest hang on point, turned 45° the way some barns show them. The paint colors tell you which event the modifier listens for, in any minigame.
