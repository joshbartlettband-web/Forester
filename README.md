# Halsey

Working title for the game developed in this repo (Forester). An encounter-driven roguelike set in a post-government Nebraska, starting in the hand-planted forest near Halsey.

- Design notes: [docs/design.md](docs/design.md)
- Art direction tests: [prototypes/look-book/look-book.html](prototypes/look-book/look-book.html)
- Handwriting font toolkit: [tools/handwriting-font](tools/handwriting-font/README.md)
- 3D print test: [prototypes/print-3d/print-3d.html](prototypes/print-3d/print-3d.html)

- `prototypes/collision/`: **Halsey Collisions**, where Gemini photographs, your drawings and work, and code print collide, with a **field guide** (`guide.html`) to every person, creature, place and story.
